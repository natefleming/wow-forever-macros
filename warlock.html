⛧Orc Warlock

Orgrimmar demon-binder. Every pet on one key, every curse on your focus, and Blood Fury that never sits idle.

Before you start:
  • Turn on the focus frame: Esc → Edit Mode → Focus Frame. Set focus with the Set focus macro.
  • Put your PvP trinket in the top trinket slot (13). Macros use the slot, so they keep working when you upgrade it.
  • Paste into Esc → Macros, then pick the question-mark icon so the button shows the spell it will cast.
  • Shortcuts: spell names have no abbreviations, but commands do. /spell is /cast, /tar is /target, /a is /assist, /script is /run. Use them when a macro is near 255 characters. /cast !Shadowform never toggles a form off, and /use item:12345 uses an item by ID if its name changes.
  • Spells and names are from the Forever beta (October 2026). Cards marked check in-game have one detail to confirm at launch.
