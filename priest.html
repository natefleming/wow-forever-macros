✶Priest

Horde: Undead, Troll

Mouseover heals, focus dispels and silences, with Undead and Troll racial spells in their own groups.

ClickYour target, or what's under your mouse
ShiftYour focus target
AltYourself
CtrlAlternate spell or an extra cooldown
Before you start:
  • Turn on the focus frame: Esc → Edit Mode → Focus Frame. Set focus with the Set focus macro.
  • Put your PvP trinket in the top trinket slot (13). Macros use the slot, so they keep working when you upgrade it.
  • Copy single macros into Esc → Macros, or download a whole set as a macro file below. Pick the question-mark icon so the button shows the spell it will cast.
  • Shortcuts: spell names have no abbreviations, but commands do. /spell is /cast, /tar is /target, /a is /assist, /script is /run. /cast !Shadowform never toggles a form off, and /use item:12345 uses an item by ID if its name changes.
  • Spells and names are from the Forever beta (October 2026). Cards marked check in-game have one detail to confirm at launch.
Download as a WoW macro file
Where should these macros go?

The per-character tab. Classic clients allow 18 here; Forever's limit isn't confirmed.

The account-wide tab, up to 120 macros, shared by every character.

Keep your existing macros (optional)

Pick the file you're replacing and the download keeps everything in it, adding these macros after. Without it, the download replaces all macros in that tab.

Only macros that are showing and ticked are included. Use the race and PvP/PvE filters above, or untick cards you don't want.

Install the file
  1. In game, type /console synchronizeMacros 0. Otherwise Blizzard's server copy of your macros can overwrite the file when you log in. Then exit WoW completely.
  2. Open your Forever game folder (in the beta it's _classic_beta_):
    Windows: C:\Program Files (x86)\World of Warcraft\_classic_beta_\
    Mac: /Applications/World of Warcraft/_classic_beta_/
  3. Go to WTF/Account/<your account>/. For All characters, the file goes right there. For This character only, go on into <Realm>/<Character>/. The folders appear after you've logged in once.
  4. Rename the old macros-cache.txt to macros-cache.bak as a backup, then copy the downloaded file in.
  5. Start WoW and type /macro to check they're there. Drag them onto your bars. You can turn sync back on with /console synchronizeMacros 1.
